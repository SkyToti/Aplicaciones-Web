¿Cómo pruebo los programas?

Crea un proyecto en NetBeans, IntelliJ o VS Code con una clase que se llame Main, borra lo que traiga (menos el renglón package …; de hasta arriba, si tu editor lo puso) y pega el programa completo de cada ejemplo. Si no tienes nada instalado, busca «compilador de Java en línea»: funciona igual desde el celular. Todos los programas de aquí se corrieron antes de publicarse, y su salida es la real.
